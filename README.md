# Astra Music Website

Astra Music's lightweight Android download website.

## Structure
- `index.html` — landing page
- `privacy.html` — privacy policy
- `terms.html` — terms & conditions
- `contact.html` — contact/support page
- `assets/` — Astra icon and selected app screenshots
- `css/` — site styles
- `js/` — interactions and scroll animation
